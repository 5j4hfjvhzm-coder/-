# 에딧 메이커 (macOS · After Effects)

레퍼런스 edit 영상 + 내 클립을 넣으면 **After Effects 프로젝트(.aep)를 자동으로 만들고**, 미리보기 영상을 보면서 **"자막 더 크게" 같은 수정 요청**을 할 수 있는 맥 앱이에요.

## 실행 방법

1. Mac에 **Xcode 16 이상**과 **Adobe After Effects**(2023 이상 권장)가 있어야 해요.
2. `EditMaker/EditMaker.xcodeproj` 를 열고 ▶︎ (⌘R).
   - 서명 오류가 나면 Signing & Capabilities → Team 에 본인 Apple ID를 고르세요.
3. **After Effects에서 한 번만**: 설정 › 스크립팅 및 표현식 › **"스크립트가 파일을 쓰고 네트워크에 액세스하도록 허용"** 켜기
4. 처음 만들 때 "에딧 메이커가 After Effects를 제어하려고 합니다" → **허용**

## 쓰는 순서

| 단계 | 하는 일 |
|---|---|
| 1. 재료 | 레퍼런스 edit 영상, 내 클립(영상·사진), 선택: 다른 음악, CC 자료(.ffx) |
| 2. 스타일 | 자막 문구(한 줄=자막 하나), 자막 스타일, CC, 효과 양, 번짐(글로우) — 전부 **AI 자동** 가능 |
| 3. 만들기 | 폰트 자동 설치 → AE가 프로젝트 생성 → 미리보기 렌더 |
| 4. 검토·수정 | 영상 보면서 채팅으로 수정 요청, 또는 타임라인에서 컷·자막을 눌러 직접 수정 → 새 버전(v2, v3…) |

결과물은 `~/Movies/EditMaker/edit-날짜/` 에 버전별로 저장돼요 (`edit_v1.aep`, `edit_v1.mp4`, 설계도 `.plan.json`).
"AE에서 열기"로 열어서 직접 더 다듬어도 돼요.

## 앱이 하는 일

- **레퍼런스 분석**: 장면 전환(컷) 위치, 음악 BPM·비트, 화면 색감, 에너지를 분석해서 컷 타이밍을 따라 해요.
- **After Effects 효과**
  - 전환: 줌 펀치, 플래시, 블러 인, CC Radial Fast Blur, 휩 슬라이드, 흔들림(wiggle), 천천히 줌인, 슬로모션
  - 자막 8종: 네온 글로우(RGB 번짐), 소프트 블러, 임팩트 팝, 타자기, 말랑 바운스, 라이트 스윕(CC Light Sweep), 글리치, 미니멀
  - CC(색보정) 조정 레이어: 밝기·대비, 바이브런스, 틴트, 샤픈, **글로우(살짝 번지는 효과)**, 노이즈, CC Vignette + 내 .ffx 프리셋
- **폰트**: Google Fonts 무료 한글 폰트 8종(검은고딕, 도현, 주아, 개구쟁이, 동글, 고운돋움, 오르빗, 가석원)을 `~/Library/Fonts` 에 자동 설치
- **AI 감독 (선택)**: 설정(⌘,)에 Claude 또는 Gemini API 키를 넣으면
  - 레퍼런스 장면을 보고 자막 스타일·색·위치, 전환 효과, CC를 골라요
  - 영상을 본 뒤 "2번째 자막 노란색으로", "플래시 빼줘" 같은 요청을 반영해 다시 만들어요
  - 키가 없으면 규칙 기반으로 만들고, 수정은 타임라인에서 직접 할 수 있어요

## 문제 해결

- **"권한이 없어요"** → 시스템 설정 › 개인정보 보호 및 보안 › 자동화 › 에딧 메이커 → After Effects 켜기
- **"결과를 남기지 않았어요"** → 위 3번 AE 스크립팅 설정 확인
- **자막 폰트가 기본 폰트로 나옴** → 폰트 설치 후 After Effects를 껐다 켜고 다시 만들기
- **AE 버전이 여러 개** → 설정 › After Effects 에서 고르기
