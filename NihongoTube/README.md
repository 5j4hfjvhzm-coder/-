# 니혼고 튜브 (일본어 버전)

**iOS·맥 앱(Xcode)은 [`ios/`](ios/README.md)** 에 있어요. 유튜브 영상을 앱 안에서 재생하고 자막도 자동으로 받아요.
아래는 claude.ai 아티팩트(웹 페이지) 버전입니다.

일본어 자막을 눌러 일→한 사전으로 찾고, 모르는 단어를 저장해 빈칸 시험으로 복습하는 웹 페이지입니다.
claude.ai 아티팩트로 올려서 씁니다 (Xcode 앱 아님).

- `web/index.html` 페이지, `web/core.js` 순수 로직 (활용형 → 기본형, 자막 파싱, 정답 판정)
- `web/d/*.json` 사전 조각 (표제어 첫 글자로 96개로 나눔), `web/d/meta.json`
- `scripts/build_ja_dict.py` 사전 만들기, `scripts/test_core.js` 로직 테스트

## 사전 다시 만들기

```bash
git clone https://github.com/Lyroxide/yomichan-ko-dic
python3 scripts/build_ja_dict.py yomichan-ko-dic web
node scripts/test_core.js
```

yomichan-ko-dic 은 한국어 학습자용 **한→일** 사전(한국어기초사전 일본어판, 네이버 한일사전)이라
일본어 대역어(読み【漢字】)를 표제어로 삼아 **일→한**으로 뒤집었습니다. 표제어 약 15만 개.
기초사전 데이터는 CC BY-SA 2.0 KR, 네이버 데이터는 원 저장소에 라이선스가 따로 적혀 있지 않습니다.

## 기능

- 자막: 유튜브 "스크립트 표시" 복사 글, .srt/.vtt/.txt (일본어·한국어 섞여 있어도 됨), 시간으로 이중자막 정렬
- 영상: 유튜브는 아티팩트 안에 넣을 수 없어 대사마다 "▶ 유튜브" 링크(그 시간부터). 영상 파일을 열면 자막을 겹쳐 재생, 전체화면, 이전/다시/다음 대사
- 한국어 자막 숨기기 + 두 번 탭해서 보기, 한국어가 없으면 Claude로 번역(선택)
- 단어 탭 → 가장 긴 일치 + 활용형 풀기(食べました → 食べる), 뜻 여러 개 골라 저장, 일본어 발음 듣기
- 단어장(검색, 원문, 유튜브 시간 링크, ★, 삭제) + 사전 검색
- 빈칸 시험: 전체 퀴즈 / 전체 테스트 / ★만, 힌트(첫 글자·기본형 읽기·한국어 자막), 저장하고 나가기 → 이어서 하기, 틀린 문제 다시
- 저장: 내 claude.ai 계정(db, 나만 보임) → 폰·맥 어디서 열어도 같은 단어장. 안 되면 이 브라우저에 저장
