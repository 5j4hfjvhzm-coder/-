니혼고 튜브자막으로 배우는 일본어
자막 넣기 · 영상 열기
유튜브 자막 가져오는 법 (PC 브라우저): 영상 아래 설명란 → 스크립트 표시 → 스크립트 창을 드래그해서 복사 → 위 칸에 붙여넣기. 자막 언어를 일본어로 한 번, 한국어로 한 번 복사해서 둘 다 붙여넣으면 이중자막이 돼요. 시간이 같이 복사되면 시간 순서로 맞춰요.
유튜브 영상은 이 페이지 안에 띄울 수 없어서, 대사 옆 ▶ 유튜브를 누르면 그 시간부터 유튜브가 새 탭에서 열려요. 영상 파일이 있으면 영상 파일 열기로 여기서 자막을 겹쳐 볼 수 있어요.
