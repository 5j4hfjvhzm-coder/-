# 니혼고 튜브 (iOS · 맥 앱)

유튜브 일본어 영상을 일/한 이중자막으로 보면서, 모르는 단어를 눌러 일→한 사전으로 찾고,
그 문장 그대로 빈칸 시험을 보는 SwiftUI 앱입니다. 영어 버전(TubeVocab)과 같은 구조이고 **유료 API·API 키를 쓰지 않습니다.**

## 실행

1. Xcode 16 이상으로 `NihongoTube.xcodeproj` 를 엽니다.
2. `NihongoTube` 타깃 → Signing & Capabilities → Team 에서 본인 Apple ID 를 고릅니다 (필요하면 Bundle Identifier 변경).
3. 아이폰/시뮬레이터를 고르고 ⌘R. 테스트는 ⌘U.
4. 맥에 설치: `sh scripts/install_mac_app.sh` (응용 프로그램 폴더에 "니혼고 튜브" 설치)

## 영상 재생

유튜브는 앱 안 재생을 자주 막아서(오류 152/153, 101/150) 세 가지 방식을 차례로 씁니다.

1. **기본 플레이어**: 앱 페이지 안의 유튜브 IFrame 플레이어 (출처 = `https://<번들 ID>`)
2. **임베드 페이지**: `youtube.com/embed/…` 를 직접 열기
3. **유튜브 모바일 페이지**: `m.youtube.com/watch?…` 를 열고 영상만 화면 가득. 주인이 임베드를 막은 영상도 재생됩니다.

10초 안에 영상이 안 뜨거나 오류가 나면 자동으로 다음 방식으로 넘어가고, 영상 아래 **다른 방식으로 재생** 버튼으로 직접 바꿀 수도 있어요.
그래도 안 되면 **유튜브 앱에서 열기**. 어느 방식이든 영상 안 `<video>` 의 시간을 읽어서 자막을 맞춥니다.

## 기능

- 일본어 자막(수동 > 자동생성)과 한국어 자막(수동, 없으면 유튜브 자동번역)을 자동으로 받아 시간으로 맞춤. `.srt/.vtt` 파일도 가능 (UTF-8, Shift_JIS, CP949)
- 영상 위 이중자막, 전체화면, 이전/다시/다음 대사, 한국어 숨기기 + 두 번 탭해서 보기
- 단어 탭 → 가장 긴 일치 + 활용형 풀기 (食べました → 食べる, 行った → 行く, 待っています → 待つ), 뜻 여러 개 골라 저장, 일본어 발음 듣기
- 단어장: 검색(히라가나로도), 원문, 영상에서 보기, ★, 삭제, 사전 직접 검색
- 빈칸 시험 (예전 빈칸 단어장 방식): 전체 퀴즈 / 전체 테스트 / ★만, 힌트(첫 글자·기본형 읽기·한국어 자막), 저장하고 나가기 → 이어서 하기, 틀린 문제 다시.
  문장 속 모양·기본형·히라가나 모두 정답 (食べた, 食べる, たべた)
- 아이폰 ↔ 맥 단어장 동기화: 단어장 탭 ☁︎ → 같은 iCloud Drive 폴더 고르기 (`NihongoTube-words.json`)

## 사전

`NihongoTube/Resources/jadict.db` (약 23MB, 표제어 15만 개)는 [Lyroxide/yomichan-ko-dic](https://github.com/Lyroxide/yomichan-ko-dic)
의 **한→일** 사전(한국어기초사전 일본어판, 네이버 한일사전)을 일본어 대역어 기준으로 **일→한**으로 뒤집은 것입니다.
다시 만들기: `sh scripts/make_dict.sh`. 기초사전 데이터는 CC BY-SA 2.0 KR.
